# News Email Notifier

This project fetches the latest news articles about a given topic using the [NewsAPI](https://newsapi.org/) and sends them via email using Python's `smtplib`.

---

## 🚀 Features
- Fetches top **20 news articles** for a specified topic.
- Extracts the **title, description, and URL** for each article.
- Sends the results in a formatted email.
- Uses Gmail SMTP (works with App Passwords for security).
